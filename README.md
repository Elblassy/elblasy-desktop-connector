# Elblasy Desktop Connector

A powerful Odoo module that transforms your Odoo experience into a desktop-like application with advanced price checking capabilities.

## Overview

Elblasy Desktop Connector allows you to use Odoo as if it were a native desktop application through advanced web desktop technology. It provides a comprehensive price checker application that connects seamlessly with your Odoo system, featuring intelligent background responsiveness that adapts to product colors for enhanced visual experience and brand consistency.

## Features

- **Desktop-like Odoo experience** with native app feel
- **Advanced price checker application** with real-time data
- **Intelligent color-responsive backgrounds** that adapt to product themes
- **Retail-optimized interface** for customer self-service
- **Seamless Odoo ERP integration** with full data synchronization
- **Customizable settings** for different retail environments
- **Mobile-responsive design** for various screen sizes
- **Real-time inventory and pricing updates**

## Supported Odoo Versions

This repository contains branches for different Odoo versions:

- **16.0** - Odoo 16.x compatibility
- **17.0** - Odoo 17.x compatibility  
- **18.0** - Odoo 18.x compatibility

## Installation

1. Clone the repository and checkout the appropriate branch for your Odoo version:
   ```bash
   git clone https://github.com/your-username/elblasy-desktop-connector.git
   cd elblasy-desktop-connector
   git checkout 16.0  # or 17.0, 18.0
   ```

2. Copy the module to your Odoo addons directory:
   ```bash
   cp -r elblasy_desktop_connector /path/to/odoo/addons/
   ```

3. Update your Odoo addons list and install the module through the Odoo interface.

## Configuration

1. Install the module from the Odoo Apps page
2. Configure desktop connection settings in your preferences
3. Access the desktop-like interface through the main menu
4. Customize the price checker for your retail environment
5. Configure product color mappings for background responsiveness
